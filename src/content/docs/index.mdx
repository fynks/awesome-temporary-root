# Root access on a locked Android bootloader, for one boot at a time.

<Aside type="warning" title="Match your exact device — safety first">
Temporary root uses kernel privilege-escalation code. A wrong profile can panic or damage your device. Confirm the exact model, firmware build, and full kernel release in the upstream project before running anything. Use only devices you own or are authorized to modify.
</Aside>

This community-maintained index tracks hardware-confirmed temporary-root targets, their exact firmware and kernel matches, and the tools that support them. It is built from [README.md](https://github.com/fynks/awesome-temporary-root/blob/main/README.md), the canonical Markdown source at the repository root.
