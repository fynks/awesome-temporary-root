Root access on a locked Android bootloader, for one boot at a time. This community-maintained index collects temporary-root knowledge, tools, modules, and device reports, distinguishing maintainer-verified results from user reports and unverified upstream candidates.

<Aside type="caution" title="Project scope">
This project accumulates knowledge and resources in one place. Porting temporary-root solutions to specific devices is out of scope; use the relevant loader's upstream project for device-specific development and help.
</Aside>

<Aside type="warning" title="Match your exact device">
Temporary root uses kernel privilege-escalation code. A wrong profile can panic or damage your device. Confirm the exact model, firmware build, and full kernel release in the upstream project before running anything. Use only devices you own or are authorized to modify.
</Aside>
